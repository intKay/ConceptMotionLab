# 信息塔 · 节奏版

启动：`node feature-v6/semantic-iceberg-rhythm/server.mjs`，打开 http://127.0.0.1:8800/ 。旧组合基板继续在8799，本目录独立保留，不覆盖PR #8。

点击进入播放本地音乐；右下“展开控件”→“展开设置”。鼠标直接观察，H/Esc恢复界面。

默认纸片由前方穿过视角，继续到身后，不再按深度自动反转；“纸片反向”保留为可选组件。纸片以视角路径为参照，独立于视角整体前行速度。关联纸片显亮期间仍会短暂聚拢，关闭关联开关可看纯流动。

新增独立开关：贴纸流动、贴纸局部刷新、贴纸局部闪烁、速度节奏变化、视角加速。共17个布尔开关，另有纸片数量、视角速度、纸片速度与音量滑块。四个已有预设保留，用户可在其上逐项组合。

视角默认速度1.8倍；纸片默认1.4倍。速度起伏是24秒一轮的平滑编排，瞬时速度在所选速度的62%至138%之间变化，音乐本身不变速；未逐鼓点听审校准。关闭节奏后匀速，关闭视角加速后恢复1倍基准。

贴纸按行交错滚动，速度比旧实验明显；只有固定的一部分文字网格柔和闪烁，非全屏明暗切换，可单独关闭。四面贴纸循环延伸，避免加速后提前离开文字空间。完整32块语料仍不相同，绕行再出现已有块属于循环，不冒称无限独立语料。

画面由绝对时间、固定语料及配置决定。tempo.js使用速度函数的解析积分，跳转不依赖历史帧。复用已有music-explorer的Three.js、音频与粒子，以及long/fonts中文字体，音乐仅本地引用，不随源码发布。

实际验证见TESTING.md；未经人工听审、全曲审美验收或MP4导出。
