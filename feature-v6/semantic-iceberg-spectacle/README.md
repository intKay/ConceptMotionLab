# 裂隙远航 · 画面表现探索

启动 `node feature-v6/semantic-iceberg-spectacle/server.mjs`，访问 http://127.0.0.1:8801/ 。原四方向比较8798、组合基板8799、节奏版8800保留。本版没有将“功能通过”当成用户审美认可。

## 这轮改动

根据用户“节奏版不如PR #3之后的版本”的反馈，审查旧洪流与节奏版截图：我判断均匀高密度墙面压平了主体层次，周期加速没有形成明显的空间事件。这是视觉设计判断，不是观众实验结论。

本版用亮部主体、暗部背景和场景节奏建立空间层次：青色裂隙光门形成强透视；中段纸片沿旋转卷流穿过视角；后段巨型“门/雨/空/无”字片成为弯曲、旋转的折页。约166–186秒收低密度与亮度，再次涌入后退为余波。旧版中央长句高亮仍默认关闭。

四面贴纸连续覆盖，但压低底色亮度；纸片保留前方→身后流向，风暴改变横向轨迹，反向仍可选。降低视角默认速度至1.35倍、纸片1.15倍，保持速度滑块；镜头倾斜与视场角变化表达卷流和失重。去掉默认圆环，避免遮挡新光门主体。

## 如何体验

点击进入播放本地音乐。右下展开控件→展开设置，有四种构图：完整“裂隙远航”、光门穿越、文字风暴、失重折页。每种仍可逐项组合。24个布尔开关及画面强度/视角速度/纸片速度/数量/音量滑块，不将效果焊死。

建议看20秒入口、112秒卷流、154秒折页、177秒喘息、212秒再涌入。同一时刻的旧洪流可在8798比较入口观看。

新光门、光带亮度和字片能量响应已有本地音频分析的bass/mid/pulse；源数据采样间隔0.05秒，来自用户本地曲目。场景结构和镜头节奏仍是艺术编排，不是自动识别副歌，更不是人工逐鼓点校准。固定时间与固定数据决定画面，支持乱序跳转。

本地out/visual-preview.mp4是9秒960×600、24fps、无音轨画面样片：三段各3秒取自72、154、212秒附近，剪切用于比较效果，不是完整作品。网页版播放原曲；不上传用户音频或样片。巨型字片是字体图像弯曲，非部首或真实笔画拆分。光门及卷流是艺术空间，非物理黑洞模拟。

Three.js、粒子和音频沿用已有music-explorer依赖，字体沿用long/fonts及OFL许可证。源码不附本地音乐，需要现有项目素材。实际验证见TESTING.md。
