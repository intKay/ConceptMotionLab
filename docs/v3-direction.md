# 第三版：连续演化与概念推进

## 根据第二版反馈的修改

- 保留 0–3 秒的爆发、冲击文字，以及 31–36 秒的波浪点阵；在新的 120 BPM 节拍上重排音乐。
- 原先 20–22 秒的静态观感改为 20–26 秒持续旋转的双股粒子流。粒子从 n = 16 延长到 64、256，横向分布随之收窄。
- 10 个镜头交界使用 1.2 秒连续粒子形变；同一批 4800 个点沿弧线迁移，几何轮廓淡出／淡入，标题在转场中点交替。
- 增加“为何中间更高”“标准差为何减半”“收敛不是单调靠近”“连续正面不改变下一次概率”四个概念层次。
- 总时长从 45 秒延至 48 秒，给降低到 120 BPM 的音乐和概念留出空间。

## 时间表

| 时间 | 画面与概念 |
| --- | --- |
| 0–4 | 火花爆发、文字起势 |
| 4–7 | 双面粒子硬币，等概率 |
| 7–10 | 二叉路径生长，2¹⁶ = 65,536 |
| 10–15 | 概率钉板，多条路径可以抵达同一个终点 |
| 15–20 | 同一批粒子升为直方图，12,870 对 1 |
| 20–26 | 双股粒子流旋转并收窄，n ×4、σ ÷2 |
| 26–31 | 12 条频率轨迹，不单调的靠近 |
| 31–37 | 波浪点阵，局部与整体的视觉意象 |
| 37–41 | 粒子环围绕 1/2，解释独立性 |
| 41–44 | 旋涡收束、粒子聚字 |
| 44–48 | 完整片名、余音淡出 |

音乐按同一时间轴重生成，并以转场前 0.6 秒开始的上升音效连接相邻镜头。20–26 秒降低鼓组密度，31 秒后恢复密度，以强弱组织节奏。

本版依然是中文字幕加音乐的短片，没有旁白。统计数据、公式与艺术性动效在 README 中注明各自含义。
