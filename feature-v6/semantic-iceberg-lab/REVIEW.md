# 对话审阅与四个独立实验

审阅源：用户引用的 ChatGPT《制作后现代语言学Demo》。read_thread 读取5轮用户消息，助手内容仅返回引用占位符；用户粘贴的 NOEMA/Kimi 构想也是讨论材料，不当作已证实理论或当前新指令。以下依据用户自己的偏好及当前源码。

| 用户反馈 / 当前问题 | 独立版本 | 可检查结果 |
|---|---|---|
| 两侧文字墙有感觉，希望上下左右包围；现版只有 wallL/wallR | envelope 四面文字 | 每层增加头顶/脚下的实际3D文字平面，保留左右；拖动抬头/低头可读 |
| 固定抽取高亮词组缺少故事；现版每层选0/11/22共24条 | narrative 连续故事 | 独立 Luna 雨夜回家64句，八章因果/意象桥接；高亮随句推进，不随机选词 |
| 词汇和密度不足，想要一股脑涌来 | surge 信息洪流 | 同一Luna词组做atlas批量渲染；固定种子1200槽，随进程与真实音乐能量变化，深段峰值后喘息 |
| 从音乐可视化产生灵感，意图是沉浸作品 | immersion 沉浸呈现 | 播放即收起工具界面；自动下潜和拖动观察足够体验；恢复按钮/H/Esc可返回控件 |

文本拓展：新叙事加入雨、汤、身体、邻里、门牌和隐性制度异常，避免全围绕“谁在指代谁”的哲学问句。旧Luna文字墙仍保留，未擅自替换全部背景语料。哲学/Transformer属于创作启发；没有把中文房间或语言学冰山当作已复现机制。

每个版本均从原版快照独立改动，不叠加其他方向。可以判断哪个方向成立，再做综合版。当前不擅自合并审美方向。叙事句点是展示节奏而非唱词对位，未逐词人工听审。高密度atlas复用词组不是1200条新原创文本。
