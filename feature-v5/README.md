# 偶然的秩序 · v5

完整成片：`out/film-v5.mp4`。224 秒，1920×1080，30 fps，6,720 帧，H.264/AAC，BT.709、yuv420p。14 场、45 个字幕节拍，本地 Noto Sans SC / Noto Serif SC。无口播，使用原创程序配乐及机械声效。

以“16 抛 12 正面，硬币偏了吗？”为线索，演出硬币、等可能路径、钉板、组合数、条件概率、概率质量与累积概率、期望、方差、大数定律、中心极限定理、置信区间与精确二项检验。

## 重建

依赖现有 Python（numpy、Pillow）、Node.js 24、Chrome、FFmpeg。字体沿用 `../long/fonts/` 及其 OFL 授权文件；制作过程不需在线下载字体。`references/` 为已核对的参考文本，不参与运行。

```powershell
python -X utf8 feature-v5/build.py
python -X utf8 feature-v5/music.py
node feature-v5/verify-model.mjs
python -X utf8 feature-v5/check_fonts.py
node feature-v5/export.mjs --verify
node feature-v5/export.mjs --shots 9,33,68,94,124,149,168,184,207,221
node feature-v5/export.mjs --from 24 --to 40 --out out/preview-galton.mp4
node feature-v5/export.mjs --out out/film-v5.mp4
python -X utf8 feature-v5/verify-media.py
node feature-v5/check-playback.mjs
```

Chromium 使用专属临时配置，不读取日常浏览器配置。受限运行环境可能需要允许启动该子进程。导出每帧从确定时间取样；几何混合两次时间采样，数字与文字在其上单独绘制，避免计数重影。字幕与主图由独立区域组成。

## 相对 v4 的主要改造

- 重写全部场景，加入雕刻硬币翻面、透视分支、逐层弹跳与落点聚合、二进制织带折叠、样本空间裁剪、概率立体柱转平面、概率天平、平方面积到贡献条、纵深频率曲线与末段放大。
- CLT 从真实样本进入均值，再显示分布；随后独立演出平移、按标准误差拉伸和统一坐标比较。频率密度随坐标变换调整，不逐场按最大柱高重新归一化。
- 区间以 25 个真实样本、均值、端点和覆盖标记相连；双侧检验把两端概率汇入面积尺，再与阈值比较。
- 224 秒原创配乐包含不同密度的章节、音色转换和 149 个机械事件记录。短转场落在 120 BPM 的小节上；长公式有阅读停留。

## 数学及演示边界

1. 橙色开场序列确有 12 个正面。后续主频率轨迹先保留该序列，再进行独立公平模拟；它不是无条件随机抽出的开头，也不是大数定律的证明。
2. 钉板是固定种子生成的 1,536 条 16 步公平独立路径；粒子最终计数与路径完全对应。理论二项图独立用组合公式计算，不冒充模拟频率。
3. 条件概率画面为六次试验的完整 64 格前缀，每格唯一；第一位为正面的 32 格中，第二位也为正面的有 16 格。不是把 16 次完整样本空间误缩成 64 条。
4. `P(X=12)=0.02777099609375`；`P(X≤12)=0.9893646240234375`；`P(X≤4 或 X≥12)=0.076812744140625`。分别是单点、累积与此例的双侧 p 值。
5. CLT 切换至 Exp(1)，n=1/4/16 分别模拟 4,608 个样本均值；只显示均值 0–4 的范围，溢出数在画面列出且计入总数。标准化段使用同一组均值直方图，密度按伸缩倍数调整；超出 z 显示窗口的尾部不重新归一化。有限样本仍偏斜；正态是渐近参考。
6. 区间切换至正态总体、已知 σ=1、n=25，演示参数 μ=0。40 条真实模拟区间中 38 条覆盖；95% 指长期重复方法的覆盖率，不能从这 40 条证明覆盖率，也不意味着任意 40 次必然有 38 次。
7. 在预设 α=.05 下暂不拒绝 H0，不代表证明公平。片中没有进行效应大小估计或检验功效分析。
