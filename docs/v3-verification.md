## 渲染与转场

- 固定种子；先渲染 12.8 秒，再跳至 41.7 秒，返回 12.8 秒，JPEG SHA-256 一致。
- 4800 个粒子、4126 个可用标题采样点、11 场景、10 次转场，转场长度 1.2 秒。
- 每次转场的开始、中点、结束共 30 个时间点，对全部 4800 粒子比较前后各 0.00001 秒的坐标。最大位移约 0.2874 像素，均低于 1 像素检查阈值。
- 修复开场节拍脉冲重置造成的位置跳变；钉板落点与直方图堆积之间使用平滑落位。
- 以上为位置连续性与确定性检查，不等同于对转场审美的自动评分。

## 概念与数据

- 4800 条 16 步路径：箱计数之和为 4800，路径终点等于成功次数的两倍减 16。
- 理论二项概率之和为 1；2¹⁶ = 65,536，C(16,8) = 12,870。
- 4800 组采样从同一初始 16 次结果扩展至 64／256 次；频率处于 [0,1]，且对应次数为整数。
- n = 16、64、256 时，理论标准差为 0.125、0.0625、0.03125；本次有限样本实测约 0.126553、0.062418、0.031040。
- 阶段之间是位置插值；画面用 n 的箭头变化表示过渡。粒子流的竖直坐标、波浪和旋涡为艺术表现。

## 复查命令

```powershell
node scripts/export.mjs --verify
ffprobe -v error -show_entries format=duration,size:stream=codec_name,width,height,r_frame_rate,nb_frames,sample_rate,channels,duration -of json out/sample-v3.mp4
ffmpeg -hide_banner -i out/sample-v3.mp4 -vf blackdetect=d=0.25:pix_th=0.015 -af ebur128=peak=true,silencedetect=n=-45dB:d=0.5 -f null NUL
```
