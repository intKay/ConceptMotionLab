# 首轮视觉样片任务书

状态：Codex 准备完成，等待 Claude 实际制作。24 秒是本轮建议的样片范围；尚未生成新动画，不是完整 v6 成片。

## 目标

把“16 次抛掷得到 12 次正面”从一条观察，转化为公平模型下可比较的结果。观众应能跟随**同一批可辨认的对象**理解“单次结果 → 多次试验的计数 → 分布中的位置”。这段用来判断 Claude 的视觉语言、场内变化与转场质量，不要求在 24 秒讲完统计推断。

视觉方向由 Claude 主导。可以改变 v5 的配色、排版、材质、镜头和节奏；保留因果连续性、中文可读性和数学含义。不要用现成 v5 镜头改色就报告完成，也不要堆无关粒子或大量术语。

## 建议的三个叙事动作

| 时间 | 必须表达的事实 | 可自主设计的部分 |
|---|---|---|
| 0–8 秒 | 16 次观察含 12 正 4 反；出现问题“硬币偏了吗？” | 硬币/印记/纸带等物体、镜头、计数出现方式 |
| 8–16 秒 | 换到“假设公平且各次独立”的模型；每组 16 次试验折叠成正面次数 X | 路径如何压成计数、重复试验如何汇聚；可选钉板之外的视觉机制 |
| 16–24 秒 | 显示模型结果的分布，清楚标出观察值 X=12；留下“这样的结果有多罕见？” | 同一物体如何进入分布、理论与模拟如何区分、结尾如何接后续推断 |

时段可在总长 24 秒内微调，不机械切成三张幻灯片。至少有一次能追踪对象身份的连续变换，以及一次有阅读停留的构图。高密度运动之后应给观众可识别的落点。

## 数学边界

- 观察序列固定为 `fixtures.json` 的 `observation.outcomes`，1=正面，0=反面。它是演示设定的观察，不是这批公平模拟中的“第一个样本”。
- 模型为 X ~ Binomial(16, 0.5)，16 次独立。共有 65,536 条等概率完整序列，按正面次数分成 17 档。6 层示意只能称前缀，不能标成完整样本空间。
- 理论柱高使用 `theory.pmf`；模拟柱高使用 `simulation.counts / simulation.trials` 并标“模拟频率”。不能把两者混用或按最大柱高各自拉满。
- 如画 1,536 条路径，应与模型中同一批粒子的实际落点对应；如为性能只展示一部分，不可把显示子集冒称全部，也不能用装饰粒子假扮样本。
- 本样片可不出现数值概率。若出现，单点 `P(X=12)=2.7771%` 不等于本例双侧 p 值 `7.6813%`。不要在样片内下“硬币公平/偏了”的结论。

## 运行接口与文件范围

只新增或修改 `feature-v6/` 及本轮交接状态；读历史模型、字体和参考即可。无需 npm 安装是现有工程的默认条件，改动依赖前说明必要性。

入口建议为 `feature-v6/index.html`，画布 1920×1080、导出 30 fps、总长 24 秒。Canvas/WebGL 均可，镜头实现自主决定。页面按时间取帧，暴露：

```js
window.__ready = () => /* 字体及数据已准备好的 boolean */;
window.__duration = 24;
window.__frame = (t) => /* 绘制 t 秒，返回 JPEG data URL */;
```

这三项是接入目标，不表示当前已有新版导出器。可以把绘制拆为 `render(t)`；预览、跳转、导出必须调用同一实现。若需要 PNG 或 WebGL 特殊管线，在交接明确接口变化，由 Codex 适配。文字避免因多重时间采样而重影。

本地服务可从根目录运行 `node scripts/preview.mjs`，然后打开 `http://127.0.0.1:8780/feature-v6/index.html`。如果 8780 已占用，先确认是否已有本项目服务，不终止不明进程。当前文件尚不存在，所以制作前该 URL 不代表可播放样片。

首轮允许无配乐，先验证视觉。若加入原创短音轨，建议以现有 120 BPM 为参考，明确主动作的声音落点并交付音源；不能复制参考作品音轨。完整配乐与音画验证由后续阶段推进。

## 样片如何评审

1. 用户看运动是否有吸引力、变形能否跟随、文字风格是否合适，再决定保留或调整；不是只看静态海报。
2. Codex 检查 16/12/4 计数、模型条件、理论/模拟标签、数轴对应和连续对象的数据来源。
3. 从编码样片查看公式/中文/字幕和转场，验证实际播放和跳转；如没有音轨，明确记录“无配乐视觉样片”。
4. 确认方向后再扩展完整分镜，按模型条件串起概率、统计推断；未确定时不抢先制作全长片。
