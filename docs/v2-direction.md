# 第二版：让粒子成为主角

用户方向：节奏更快、粒子更丰富、想象力更强。

旧版为五段相近构图的说明画面。新版以粒子自身的形态转变组织剪辑：一次爆炸打开可能性，硬币旋转后成为分岔网络，路径落入钉板并堆成二项分布。统计解释之后进入环、波、旋涡，最终聚合成标题。

- 45 秒长度保留；音乐 96 → 144 BPM，场景 5 → 11 段，开场另有每两拍一次的文字切换。
- 增加纵深、旋转视角、发光拖尾、密集点阵、聚字与粒子散开。用经过的发光竖向光带衔接切镜。
- 配乐结构为开场启动、打击与旋律加入、中段减配器、高潮恢复全编制、结尾衰减。切镜及主要冲击由同一份音效提示表驱动。
- 统计画面与自由意象分工明确；数据只由固定种子模型生成。快速渲染不依赖播放历史。

审片重点：硬币旋转不穿过标题；收敛线不遮盖大字；底部字幕保持可读；概率地形的纵深不暗示额外统计变量；聚字轮廓可辨；切镜无长黑场；结尾音画同时收束。
