# 210 秒分镜与节拍

120 BPM，1 小节 2 秒；十段边界都在小节上。内部文字和强调可落在半拍/整拍。橙色 `12/16` 在概率模型与最终检验之间作为可识别的信号。轻纸色用于条件筛选、矩、抽样分布与区间；深色用于路径、分布、频率与检验。每段内有至少三次意义推进。

| 时间 | 场景内部的动作与概念 |
|---|---|
| 0–14 | 16 个事件绕粒子场依次出现，12 个亮橙、4 个蓝色；由“16 次抛掷”冲击切到 `12/16`，再转为“偏了吗？”的全屏提问。 |
| 14–38 | 二叉路径逐层展开，计数滚到 `2^16`；路径点沿层级迁移；次序折叠后落成 17 格样本直方图，扫光比较中心 8 与观察 12。理论路径数与演示粒子明确不同。 |
| 38–60 | 暖纸上的 64 格 6 位前缀示意先全部开放，再按第一枚正面筛成 32 格，第二枚正面筛成 16 格；旁边显示条件概率分母；最后强调独立时下一枚仍为 1/2。 |
| 60–84 | 显示随机变量 `X` 从路径到正面次数的映射；17 个理论二项概率柱升起，扫描光点逐格读数；12 处变橙，标出单点 2.78%，提示它还不是检验 p 值。 |
| 84–108 | 概率重心落在 8；每个取值的平方距离被逐格聚焦，得 `Var=4`、`SD=2`；同一中心的形状回缩，以“中心”和“散开”分开解释。 |
| 108–132 | 主轨迹从 12/16 继续模拟到 n=1200，另外 12 条淡色轨迹渐显；移动点与 n/频率读数同步；曲线保留向外起伏，字幕指出大数定律并非逐步更近。 |
| 132–156 | 明确切换到指数分布新模型，展示 `n=1` 的偏斜、`n=4` 的中间状态、`n=16` 的集中形状；直方图由模拟生成，扫点和标准误差数字同步改变。 |
| 156–180 | 先展示一个总体与抽取点，再将 40 条真实模拟置信区间逐条生成；固定参数线不动，区间移动、橙色表示未覆盖；计数由实际模拟结果实时更新。 |
| 180–200 | 回到原硬币，公平模型的二项柱阵亮起双尾 `X≤4` 与 `X≥12`；面积聚合为精确 `p=0.0768`；数值与 α=.05 对比，并给出“暂不拒绝 H0”的有限结论。 |
| 200–210 | 贯穿全片的橙色观察值退场，数学与统计两条线聚到片名；声音减密并淡出。 |

## 文字与画面

29 个文字节拍大多持续 6–8 秒。场内定义、计数和公式与物件同位，底部的两行解释用背景实底与画面隔离；镜头边界上的瞬时淡出/入场不叠字。字体由打包的 Noto Sans SC、Noto Serif SC 加载，留出约 80 px 边距。成片从压缩视频重新抽帧检查，见 `out/video_contact.jpg`。
