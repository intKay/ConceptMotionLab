# 2026-10-12 用户反馈沉淀

以用户最后明确的“组合第1、第3、第4方向”为准：四面文字、信息洪流、沉浸呈现进入下一版基板。用户称信息洪流可能是本轮最佳方向，肯定稀疏→过载、深层流向反转及蓝→紫颜色变化。连续长句字幕的感受不足，不作为默认中心展示；该实验仍在上一轮目录和PR#5保留。

统一术语：墙面/上下表面的文字是**贴纸**；中间沿纵深流动的文字是**纸片**。关联显亮应从实际纸片中选取，有足够停留时间，属于可选模块。

贴纸要求：四面连接，讨论间隔的实际原因；不要整段/整面照搬重复，允许局部词语或意象重复。直接鼠标观察减少操作选择；控件可以展开/收起。小组成部分保留，可拆开或再次组合。

新提议：信息塔/文字海洋/被淹没的声音；黑洞；部首及单笔画拆分；局部文字刷新、行流动与扭曲；矩形/长方体堆叠旋转、重力错觉；纸片快慢分层与拖影。

这份文件记录反馈，不代表所有建议已完成或效果已验收。实施和准备范围见 EXPLORATION.md。
