# v6 视觉样片设计说明

24 秒、1920×1080、30 fps，无配乐视觉稿。作者：Claude（2026-10-09）。入口 `index.html`，源码 `film.js`，数据只读自 `../feature-v5/model.js`。

## 视觉语言

- **材质**：一页实验记录纸（米色底、淡横线、固定噪点、暗角）。与 v5 的深青底＋橙色刻意拉开。
- **配色**：墨蓝黑 `#16203a`（文字、理论轮廓）、朱砂 `#d63f29`（**只**属于那一次观察）、青蓝 `#27577a`（1,536 组模拟）。三色各对应一种数据身份，不混用。
- **字体**：Noto Serif SC 负责结论与数字（大问题、读数、X 轴），Noto Sans SC 负责注记与图例（加字距的小标题）。均取自 `../long/fonts/`。
- **镜头**：单一连续世界，只有缓慢推近与一次终段推近（18.3–21.6 秒，1→1.3 倍）；没有硬切。文字在屏幕层，不随镜头缩放，也不做多次时间采样，因此无重影。

## 连续对象与数据对应

同一批对象贯穿全片：**16 枚硬币 → 一条路径 → 正面次数 X → 分布里的一个标记**。

| 时间 | 画面 | 数据 |
|---|---|---|
| 0.7–4.2 | 16 枚硬币依次翻面，读数 5→12 正、n→4 反 | `observation.outcomes`，12 正 4 反 |
| 4.3–7.6 | 正面抬起、反面压暗，“硬币偏了吗？” | 同上 |
| 7.5–9.5 | 同样 16 枚硬币展开成钉板上的一条路径（正＝右、反＝左），终点落在 X=12 | 路径 `x = 960 + (累计正面 − 步数/2)·68` |
| 9.7–15.5 | 1,536 组公平模拟逐一走完 16 步，落入各列叠成点阵 | `particles` 的 `cum`/`heads`/`rank`，不重抽 |
| 15.9–18 | 观察路径收拢成一个标记，落到 X=12 | |
| 16.3–19 | 理论轮廓 `1536·P(X=k)` 从中间向两边升起 | `choose(16,k)/65536` |
| 18.3–24 | 镜头推近，图例沉到图下，“这样的结果，有多罕见？” | |

- **同一刻度**：每个点＝一组模拟，点阵格 8×PITCH，高度 = 组数 × 1.0625 px；理论轮廓用同一比例，**不按最大柱高各自拉满**。左侧虚线参考线为 50…300 组。
- **身份区分**：红色观察不在 1,536 组之内（屏幕上标“固定种子 · 与左侧的观察无关”）；模拟是实心点阵，理论是空心轮廓，图例明示。
- 画面中没有出现概率数值，没有“公平／偏了”的结论；单点 `P(X=12)` 与双侧 p 值在样片内都未显示。

## 节奏

0–7.6 读数与提问（停留约 2.3 秒）→ 7.5–9.5 变形 → 9.7–15.5 高密度落点 → 15.5–18 静下来对照 → 18.3–24 推近并留问题（末 2.4 秒无运动，仅标记脉冲）。

## 下一段如何衔接

结尾停在 X=12 的红色标记与问题上。续写时：以标记为起点，把 X≥12 与对称的 X≤4 两端染色并累加面积，得到 `7.6813%`（需与单点 `2.7771%` 明确区分）。镜头保持这一推近后的构图即可无缝接入。

## 已知限制

- 无配乐；预览页无音频。
- 点数与点阵格在 1.3 倍镜头下已清晰，但在 1080p 以下缩放时点阵会糊成纹理。
- 钉点只是示意格点，粒子并未发生碰撞；路径取自固定数据，不是物理模拟。
