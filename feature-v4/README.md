# 《不确定的形状》重构版

210 秒，1600×900，30 fps，120 BPM。以“公平硬币抛 16 次，观察到 12 次正面，是否偏了？”贯穿全片。十个不等长段落，29 个文字节拍，场景内部还有切换、扫描、变形和计数推进。旧版在 `../long/`，没有覆盖。

## 重建

```powershell
python feature-v4/build.py
python feature-v4/music.py
python feature-v4/check_fonts.py
node feature-v4/export.mjs --verify
node feature-v4/export.mjs --out out/film-v4.mp4
```

成片：`feature-v4/out/film-v4.mp4`。项目根目录预览服务若已运行，可打开 `http://127.0.0.1:8780/feature-v4/index.html`。两种 Noto SC 字体由 `../long/fonts/` 本地加载，授权文本也在该目录。导出与实时预览依赖同一 `film.js` 的确定性时间函数。

## 叙事和验证边界

- 16 次公平独立抛掷的路径数、组合数与理论二项概率由公式计算。粒子和频率路径是固定种子模拟。`12/16` 的双侧精确 p 值为 `0.076812744140625`。
- 大数定律画面的一条主频率轨迹，前 16 次恰有 12 次正面，后续 1184 次按固定种子继续生成；其他淡色路径为独立模拟。轨迹不作为大数定律的证明。
- 中心极限定理段落切换到指数分布新模型，`n=1,4,16` 的柱图来自各 4600 组模拟样本均值。其均值与标准差都为 1；标准误差 `1/√n`，极限叙述需独立同分布及有限方差等条件。有限 `n` 的柱图不等于严格正态。
- 区间估计又切换到总体正态、已知 `σ=1`、`n=25` 的新模型。40 条区间由真实固定种子模拟生成，实际覆盖数由程序计算并显示。95% 是重复使用该程序时的理论覆盖率。
- 假设检验回到硬币。双侧“至少同样极端”定义为 `X≤4` 或 `X≥12`；`p=0.0768>0.05`，结论是暂不拒绝 H0，并非证明硬币公平。
